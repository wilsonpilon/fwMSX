# resource/

Diretorio reservado para codigo-fonte de terceiros usado como material de
estudo: o fMSX original e outros emuladores/ferramentas de MSX cujo
codigo sera lido, comparado e, quando fizer sentido, traduzido ou
incorporado ao fwMSX.

Ainda vazio -- sera populado nas proximas fases do projeto (ver
[doc/SPEC.md](../doc/SPEC.md), secao "Proximas fases").

Nada aqui e compilado como parte do build oficial do fwMSX (ver
`CMakeLists.txt` na raiz); este diretorio e apenas referencia de leitura.
