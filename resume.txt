== O projeto em duas linhas ==
fwMSX: emulador de MSX1/MSX2/MSX2+ de ESTUDO (Wilson Pilon), em C, C++, Assembly (NASM, ABI dupla Win64/SysV) e Fortran; cada fase relevante exercita as 4
linguagens. Veio do fMSX (Marat Fayzullin, com o aval dele). Meta de medio prazo: integrar ao msxide num utilitario "MSX-PoorManOS".

== Pegadinhas de ferramenta (aprendidas na dor) ==
- Heredocs/`python -` com barra invertida corrompem arquivos: um `\\n` dentro de string C++ virou QUEBRA DE LINHA REAL. Para qualquer texto com `\` use as
  ferramentas Write/Edit (ou grave um .py com Write e rode-o). Confira com `awk` se ha' aspas abertas apos editar por script.
- gfortran so' compila no PowerShell (no Git Bash o f951 da' segfault); `iachar` derruba o f951 (use `ichar`).
- Build do WSL pode ser morto por falta de memoria; se acontecer, rode `./build.sh` de novo (e' incremental).
- Rodar build.ps1 pelo bash gera build velho; use a ferramenta PowerShell.
- Em teste de ponta a ponta no modo RAPIDO de fita, o BLOAD termina dentro dos quadros da tecla ENTER: ponha o breakpoint ANTES de digitar.
- fwasm: dentro de `namespace fwasm { namespace {` um nome `tape::` pode resolver errado e causar "undefined reference"; inclua headers no topo, fora do namespace.
- Estilo: `git status` mostra dist/*.exe e binarios de teste modificados -- NAO commitar (dist/fwMSX.exe e' rastreado e e' regenerado a cada release).
