fwMSX -- como retomar (atualizado em 2026-10-19, apos a 1.40.4)

== Em OUTRO computador (o caminho que importa) ==
1. git clone / git pull de origin main (traz tudo: codigo, docs, ROMs de teste, dist/).
2. Abrir o Claude Code na pasta do repositorio: ele le o CLAUDE.md sozinho (regras fixas de release).
3. Pedir: "leia o OUTLINE.md e me diga onde paramos". O OUTLINE.md (secao 2) e' o "onde paramos" oficial.
   `claude --resume` NAO funciona em outra maquina (so' na mesma onde a sessao rodou).
